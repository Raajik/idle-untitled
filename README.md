# Immortal Isparian Incremental (III)

**▶ Play it: https://raajik.github.io/idle-untitled/**

A text-based idle RPG set in Asheron's Call's world of Dereth: your hero auto-battles through six monster regions, earning XP, pyreals, and loot with every kill. Spend XP to raise your six attributes (Strength, Endurance, Coordination, Quickness, Focus, Self), equip gear across five rarities, pour pyreals into percentage-scaling training upgrades, and when you hit the wall — Rebirth to reset the run in exchange for permanent Hero Soul upgrades. Death is free: you respawn at your Lifestone. Progress continues while you're away, the interface unfolds new panels as you unlock features, and there are no energy systems, tokens, or premium gates of any kind — everything is earned by playing.

## Development

Vanilla JS ES modules, zero dependencies, no build step.

```sh
npx serve .        # or any static server, then open the shown URL
npm test           # run unit tests (node --test)
```
