# Idle Untitled

**▶ Play it: https://raajik.github.io/idle-untitled/**

A text-based idle RPG for the browser: your hero auto-battles through six monster zones, earning XP, gold, and loot with every kill. Allocate stat points, equip gear across five rarities, pour gold into percentage-scaling training upgrades, and when you hit the wall — Rebirth to reset the run in exchange for permanent Hero Soul upgrades. Progress continues while you're away, the interface unfolds new panels as you unlock features, and there are no energy systems, tokens, or premium gates of any kind — everything is earned by playing.

## Development

Vanilla JS ES modules, zero dependencies, no build step.

```sh
npx serve .        # or any static server, then open the shown URL
npm test           # run unit tests (node --test)
```
